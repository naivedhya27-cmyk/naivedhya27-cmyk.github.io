Work

What I have built and run with my co-founder at Scholar Scribe Consulting, most of it for client work. Client names stay private; the numbers are our own.

  1. The operations agent

    Scholar Scribe Consulting · 2025 to now

    The set-up that runs our delivery: an AI coding agent working from short instructions in plain language, with house rules, client context and the state of each workstream kept in plain files it reads every session, and the fixed steps run as R scripts. From 3 October to 7 November 2026 it handled 3,289 instructions across 259 workstreams, a median of 27 tool actions and 10.4 minutes each. It never types a client's password, and a person reads every client message before it goes out. The numbers are in this field note.

  2. An evidence-synthesis pipeline

    Scholar Scribe Consulting · 2025 to now

    Behind 60+ delivered systematic reviews and meta-analyses. Agents plan; R runs the searches, screening, data extraction, risk of bias, GRADE and the meta-analysis. An R second reviewer and an integrity checker block unsupported claims before anything goes to a journal.

  3. A clinical note reader for drug-induced liver injury

    Delivered to a hepatology client

    A fine-tuned 135M-parameter model that turns drug-induced liver injury notes into structured fields, with the R ratio, Hy's law and RUCAM 2016 worked out in code. It is a 64 MB file that runs on a laptop CPU with no install.

  4. PramaanBench

    Open benchmark, in build

    Frontier models tested on Indian health, law and farming questions made from real records: 1,968 Indian case reports, 159,998 farmer questions and 496 court judgments, with answer keys quoted from Indian guidelines and statutes, in English, Hindi and Hinglish. It runs in OpenAI simple-evals and Inspect.

  5. SS Arena

    Exam practice app

    Practice for India's NEET SS and INI-SS exams: 1,006 questions over 90 topics, with streaks, leagues, duels and timed mocks. Built on Firebase and Vercel, and also served inside Claude as an MCP connector.

  6. Tend

    Care-circle app for Amazon Alexa+

    A self-hosted MCP server with 20 tools, OAuth account linking, a browser simulator of the Echo Show and 66 automated tests.

  7. Fair Trial

    Hackathon entry on YouCam's skin AI

    A split-face home trial for skincare products. It finds the treated side 96% of the time, and its verdict engine holds false "it works" calls to 4% by design. The code is on GitHub.

  8. MARK C

    Decision-simulation startup

    Traced why the Monte Carlo engine returned one flat number, and sent pull requests that close a denial-of-service hole, add security headers and harden rate limits.
